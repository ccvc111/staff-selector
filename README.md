# 员工选择系统

一个简单易用的员工选择小程序，支持电脑和手机直接打开使用。

## 🌐 在线访问

**GitHub Pages 地址**: https://你的用户名.github.io/staff-selector/

## 📱 功能特点

### 用户选人页面
- 📷 员工照片卡片展示
- 🔍 实时搜索员工姓名
- 💰 按价格范围筛选
- 🟢 在线/休息/离线状态标识
- 👆 点击查看详情并选择

### 员工页面
- 👤 员工身份登录
- 📊 个人数据统计
- 🔄 一键切换工作状态

### 管理员后台
- 📈 实时数据统计面板
- ➕ 添加新员工
- ✏️ 编辑员工信息
- 🗑️ 删除员工
- 📤 照片上传

## 💾 数据存储

所有数据存储在浏览器本地（localStorage），无需服务器，刷新页面数据不会丢失。

## 📁 文件说明

| 文件 | 功能 |
|------|------|
| `index.html` | 首页导航 |
| `user.html` | 用户选人页面 |
| `staff.html` | 员工状态管理页面 |
| `admin.html` | 管理员后台 |

## 🚀 本地使用

直接双击 `index.html` 文件在浏览器中打开即可。
